## สรุปการตัดสินใจของเจ้าของช่อง (เซสชัน 2026-11-21/22)
- **เปลี่ยนแนวช่องเป็น "การ์ตูนเล่าเรื่อง"** (อ้างอิงสกิล `.claude/skills/cartoon-short/` — ใช้โครงเรื่อง แต่ภาพ/เสียงเป็นของช่องเราเอง)
- **เรื่องแนวไหนก็ได้** (ผี ลี้ลับ ตลก ประวัติศาสตร์ ชีวิต) แต่ต้องมีข้อเท็จจริงจริง + แหล่งอ้างอิง เหมือนเดิม
- **น้องสงสัยเป็นตัวเอกทุกเรื่อง** — เป็นคนเจอเหตุการณ์ สงสัย และเฉลยเอง ไม่ใช่ยืนดูมุมจอ (เจ้าของช่องบอกว่ายืนข้างๆ แล้วเกะกะ)
- **ตัวละครเสริมแล้วแต่เนื้อเรื่อง** — วาดด้วย `kid()` ลายเส้นเดียวกัน (ดู `character/README.md` หัวข้อ "ตัวละครอื่นในเรื่อง") ห้ามมีแว่นกลมและผมชี้ ? (สงวนให้น้องสงสัย)
- **พูดกับคนดูว่า "คุณ"** ได้ (เช่น "ถ้าคุณตื่นมาแล้ว…") ภาพเป็นน้องสงสัยแทนคนดู
- **ตอนจบ = เฉลย → ท่าดันแว่น "รู้เรื่องทั้งหมดแล้ว / พวกมึงฉลาดขึ้นแล้วนะ" → การ์ด "ตอนหน้า: …"**
- **ตัวดึงกลับช่วง 8–13 วิ บังคับ** (ปมค้าง ⭐ เจ้าของช่องชอบ / ตุ้งแช่สำหรับเรื่องหลอน) — อยู่ใน show bible แล้ว
- **ซาวด์คลอตามโทนเรื่อง** (`"mood": "dark"` หลอน / `"warm"` อบอุ่น) + เอฟเฟกต์ "ดิ้นไม่หลุด" (`"struggle": true`) + หัวใจเต้น
- **จังหวะเร็ว:** tempo 1.2 + ช่วงเว้น ~0.2 วิ (เจ้าของช่องบอก "ดีละ")
- **ต้นแบบที่เจ้าของช่องชอบ:** `episodes/TEST-sleep-paralysis/` (story.json + คลิป v4) — ใช้เป็นตัวอย่างรูปแบบ

## งานที่ 1: เปลี่ยนเอกสารและทีมเป็นแนวเล่าเรื่อง (ทำก่อน EP003)
1. **`docs/show-bible.md`** — เขียนหัวข้อ "แนวช่อง" และ "โครงคลิปมาตรฐาน" ใหม่เป็นแบบเล่าเรื่อง:
   - โครง 4 จังหวะ: ฮุก ≤12 คำ พูดกับ "คุณ" → การ์ดตัวเลขจริง 1–3 ใบ (แหล่ง: ผู้แต่ง ปี วารสาร) → หักมุมที่ 60–75% → เฉลย + ดันแว่น + การ์ดตอนหน้า
   - ตัวดึงกลับ 8–13 วิ และ 25–35 วิ (มีแล้ว)
   - น้องสงสัยเป็นตัวเอก / ตัวละครเสริม / ห้ามแว่น+ผมชี้กับตัวอื่น
   - mood dark/warm, ตัวอย่างฉากที่มี (`tools/story/scenes.js`: bedroom_night, bedroom_day, dark, cream, street_night)
2. **`.claude/agents/scriptwriter.md`** — ผลงานเปลี่ยนเป็น `story.json` + `script.tts.txt` (+ `script.md` ตารางย่อสำหรับตรวจ) ตามสคีมาใน docstring ของ `tools/story/build.py`; ระบุ effect ที่ใช้ได้: `struggle`, `jumpscare`, `enter:"fade"`, `lying`, `shake`, `push`, `card`, `clock`, `outro`, `next`, `mood`; ทุกบรรทัด TTS จบด้วยเครื่องหมาย; ≤3 วิ/ประโยคหลังเร่ง 1.2 (≈ ≤ 14 พยางค์)
3. **`CLAUDE.md` pipeline** — ขั้น 5–6 เปลี่ยนเป็น: พากย์ (`tools/audio/tts_elevenlabs.py`) → `bash tools/story/make.sh episodes/<EP>` (นิครันเองได้ ไม่ต้องเรียก animator) → ดู `video/frames/sheet.png`
   - `animator` ใช้เฉพาะเมื่อเรื่องต้องการ **ฉาก/พร็อพใหม่** ที่ยังไม่มีใน `scenes.js` (ให้เพิ่มเข้า scenes.js เพื่อใช้ซ้ำ ไม่เขียนเฉพาะตอน)
   - `qa-reviewer` โหมดคลิปตรวจจาก `frames/sheet.png` + ffprobe/ebur128 + เฟรมเฉพาะจุด
4. **`.claude/agents/topic-scout.md`** — หัวข้อต้องเป็น "เรื่องที่เล่าได้" มีตัวละคร/เหตุการณ์ + ข้อเท็จจริงจริงที่หักมุมได้; แนวไหนก็ได้
5. **`.claude/agents/animator.md`, `qa-reviewer.md`, `marketer.md`** — อัปเดตให้สอดคล้อง (ตุ้งแช่/ซาวด์คลอ/ตัวดึงกลับ; marketer ระวังปกห้ามใช้เฟรมตุ้งแช่ที่อาจโดนลดการมองเห็น)
6. **ความยาว:** เป้า 45–60 วิ (ไม่เกิน 70) — คลิปทดสอบยาว ~31 วิ เรื่องจริงควรมีเนื้อหามากกว่านี้ (ปมว้าว 2–3 จุด)

## งานค้างอื่น
- **EP002** (แนวเดิม) — **เจ้าของช่องยกเลิก ไม่โพสต์ (2026-11-22)** เริ่มแนวใหม่เลย เก็บไฟล์ไว้เป็นประวัติเท่านั้น
- **ชื่อตัวละคร** ยังไม่เลือก (ตัวเลือก: น้องเอ๊ะ, น้องรู้ป่าว, คิวคิว, ไวไว ฯลฯ) — ปัจจุบันใช้ "น้องสงสัย"
- **"คุณ" vs "เธอ":** แนวใหม่ใช้ "คุณ" (ตามสกิลและ EP002) — ยืนยันกับเจ้าของช่องตอนอัปเดต show bible
- **ข้อจำกัดเครื่องมือที่รู้แล้ว:** ยังไม่มีปากขยับตอนพูด; การ์ดตอนหน้าตัดบรรทัดตามช่องว่าง (เขียนข้อความให้ไม่มีช่องว่างกลางวลี); `assemble.py` จะ exit 2 เมื่อมีประโยค > 3 วิ (make.sh ทำต่อแต่เตือน)
- **ประหยัดโทเค็น:** เจ้าของช่องต้องการ ≤ 2 รอบโควตาต่อคลิป — ใช้ make.sh แทน animator, agent ใหม่ทุกตอน, sonnet สำหรับ agent ส่วนใหญ่
