# คู่มือรายการ (Show Bible) — "น้องสงสัย"

ทุก agent ต้องอ่านไฟล์นี้ก่อนเริ่มงาน ถ้าคำสั่งใดขัดกับไฟล์นี้ ให้ถามโปรดิวเซอร์ (นิค)

## ช่อง
- **แพลตฟอร์มหลัก:** TikTok (แนวตั้ง 1080×1920)
- **แนว:** **การ์ตูนเล่าเรื่อง** (เปลี่ยนแนว 2026-11-22) — น้องสงสัยเจอเหตุการณ์ สงสัย แล้วเฉลยด้วยข้อเท็จจริงจริงที่หักมุม
  - เรื่องแนวไหนก็ได้: ผี/ลี้ลับ ตลก ประวัติศาสตร์ ชีวิตประจำวัน ร่างกาย — แต่ **ทุกเรื่องต้องมีข้อเท็จจริงจริง + แหล่งอ้างอิง** เหมือนเดิม
  - แนว "ถ้าคุณ… จะรอดไหม" (เจ้าของช่องส่งคลิปตัวอย่างมา 2026-11-23: ช่องอื่น "เรื่องนี้น่ากลัว | ตอน หมอก Ep.1" ~200K ไลก์ — ใช้เป็นแนวทางรูปแบบเท่านั้น ห้ามลอกเรื่อง/ภาพ/ตัวละคร)
    - เจ้าของช่อง: **"ไม่เอาสาระมาก เน้นหัวข้อแปลกๆ"**
    - โครง: **สถานการณ์แปลก/อันตรายในที่ไทยๆ** พูดกับ "คุณ" + นาฬิกา (เช่น "ถ้าหมอกลงหนัก ตอนคุณอยู่ในเซเว่น ตีสี่สิบนาที") → **กฎเอาตัวรอดข้อแรก** ป้ายแดง ("อย่าเดินไปที่รถ!") → **เหตุผลสั้นๆ จากข้อเท็จจริงจริง 1 ข้อ + แผนภาพ** (คนปิดตาเดินวนเป็นวงแคบกว่า 20 เมตร) → **"แต่คืนนี้… นั่นยังไม่น่ากลัวที่สุด"** → ตัวละครใหม่โผล่ (ไรเดอร์ พนักงาน) → ค้างเป็นซีรีส์ Ep.1/2/3
    - สาระน้อย 1–2 ข้อ ฝังอยู่ในกฎเอาตัวรอด (ยังต้องมีแหล่งจริงตามกฎเหล็ก) · ซับสั้นมาก 2–5 คำ คำสั่งสำคัญเป็นป้ายแดง · ลุ้น/ค้างเป็นหลัก
  - ต้นแบบที่เจ้าของช่องชอบ: `episodes/TEST-sleep-paralysis/` (story.json + คลิป v4) — ใช้ดูรูปแบบ (เรื่องจริงต้องยาวกว่าและมีปมว้าว 2–3 จุด)
- **กลุ่มคนดู:** วัยรุ่น–วัยทำงานไทย (ม.ปลายขึ้นไป)
- **ความยาว:** เป้าหมาย 45–60 วินาที ยืดได้ถึง 70 วินาทีเมื่อเรื่องต้องการ — แนว "ถ้าคุณ… จะรอดไหม" เกิน 1 นาทีได้ (เจ้าของช่อง 2026-11-23: "เกิน 1 นาทีได้ ขอให้น่าสนใจ ไม่ตัดคำพูดมากไป") ประโยคพูดต้องเป็นธรรมชาติ ครบความ ไม่ห้วนแบบพาดหัว — ยาวเกินให้แบ่งบรรทัด ไม่ใช่ตัดคำ
- **จังหวะพูด:** เร็วและกระชับกว่า EP001 (เจ้าของช่องบอกว่า EP001 ยืดไป) — เสียงพากย์เร่งด้วย `tempo` ใน `tools/audio/voice.json` (ตอนนี้ 1.2) และเว้นช่วงระหว่างประโยค ~0.2 วิ ความยาวที่เพิ่มขึ้นให้ใช้ใส่เนื้อหา ไม่ใช่พูดช้าลง
- **เป้าหมายธุรกิจ:** สร้างผู้ติดตาม → TikTok Shop Affiliate (≥1,000 ผู้ติดตาม) → งานแบรนด์

## ตัวละคร: น้องสงสัย (ตัวเอกทุกเรื่อง)
- **บทบาท:** เป็นคนเจอเหตุการณ์ สงสัย และเฉลยเอง — **ไม่ใช่ยืนดูมุมจอ** (เจ้าของช่องบอกว่ายืนข้างๆ แล้วเกะกะ) เมื่อบทพูดกับ "คุณ" ภาพเป็นน้องสงสัยแทนคนดู
- เด็กหัวโตแบบจิบิ ผมดำ แว่นกลมกรอบหนา ฮู้ดสีส้ม ผมชี้บนหัวเป็นรูป `?` ที่เปลี่ยนตามอารมณ์
- **นิสัย:** กวนๆ ซนๆ แต่น่าเอ็นดู ถามแทนคนดู แต่ชอบแกล้งทำเป็นรู้คำตอบก่อน บางทีก็โดนจับได้ว่าผิดแล้วเขิน
- **ไลบรารีและท่ามาตรฐาน:** `character/README.md`
- **ห้าม** เปลี่ยนรูปร่าง สี หรือลายเส้นของตัวละครโดยไม่ได้รับอนุมัติจากเจ้าของช่อง

## ตัวละครเสริม
- มีแล้วแต่เนื้อเรื่อง (ผี แม่ เพื่อน นักวิทยาศาสตร์ในประวัติศาสตร์ ฯลฯ) วาดด้วย `kid()` ลายเส้นเดียวกัน — option ดู `character/README.md` หัวข้อ "ตัวละครอื่นในเรื่อง"
- **ห้ามแว่นกลมและผมชี้ ?** (`gl:"none"`, `ah:"none"`) และควรปิด `pocket`/`strings` — สงวนให้น้องสงสัยเท่านั้น
- ประกาศใน `"cast"` ของ story.json (เช่น `"G"` = ผี) แล้วอ้างด้วย `"who"`

## ลายเส้นและสี (ใช้กับภาพประกอบทุกชิ้นด้วย)
- เส้นขอบสีเข้ม `#2B2B2B` หนา, มุมมน, สีพื้นเรียบ (flat) ไม่มีไล่เฉด ไม่มีภาพถ่าย
- พื้นหลังหลัก `#FFF8EC` (ครีม)
- สีหลัก: ส้มฮู้ด `#FF8C69`, ส้มเข้ม `#E0704F`, เหลือง `#FFD84D`, ชมพูแก้ม `#FF9AA2`, ผิว `#FFE0C2`
- สีเสริมสำหรับภาพประกอบ: ฟ้าน้ำ `#9ED8FF`, เขียวมิ้นต์ `#7FD6C2`
- ภาพประกอบ (นิ้ว น้ำ อวัยวะ สิ่งของ) วาดเป็น SVG ด้วยโค้ดในลายเส้นเดียวกัน — **ห้ามใช้ภาพจากเว็บ**

## น้ำเสียงและภาษา
- ภาษาพูดกันเอง สั้น กระชับ มีจังหวะมุก
- เรียกคนดูว่า **"คุณ"** (แนวเล่าเรื่อง เช่น "ถ้าคุณตื่นมาตอนตีสาม…") — "พวกมึง" ได้เฉพาะในท่าปิดคลิป (ประโยคประจำ); "เธอ" ใช้ในตอนแนวเดิม (EP001–002)
- ห้ามคำหยาบแรงกว่า "มึง", ห้ามเหยียด, ห้ามล้อเลียนกลุ่มคน
- ทุกข้อเท็จจริงต้องจริงและมีแหล่งอ้างอิง (ดูกฎการวิจัย)

## โครงคลิปมาตรฐาน (เล่าเรื่อง 4 จังหวะ)
| จังหวะ | เวลา (คลิป ~50 วิ) | เนื้อหา | ภาพ/effect ที่ใช้บ่อย |
|---|---|---|---|
| 1. ฮุก | 0–3 วิ | ≤ 12 คำ พูดกับ "คุณ" เริ่มกลางเหตุการณ์ ห้ามเกริ่น/ทักทาย | ฉากเปิดสะดุดตาตั้งแต่เฟรมแรก, `clock`, `push` |
| 2. เรื่อง + ข้อเท็จจริง | 3 วิ – ~60% | น้องสงสัยเจอเหตุการณ์ลุ้นขึ้นเรื่อยๆ แทรก **การ์ดตัวเลขจริง 1–3 ใบ** (`card` — `src`: ผู้แต่ง ปี · วารสาร) | `struggle`, `enter:"fade"`, `shake`, ตัวดึงกลับ 8–13 วิ |
| 3. หักมุม | 60–75% ของคลิป | ความจริงที่คนไม่คาด ("แต่เดี๋ยวก่อน… มันไม่ใช่ผี!") | `jumpscare` (เรื่องหลอน) / เปลี่ยนฉากกะทันหัน / ซูมแรง |
| 4. เฉลย + ปิด | ~4–6 วิสุดท้าย | เฉลยสั้นๆ → ดันแว่น "รู้เรื่องทั้งหมดแล้ว / พวกมึงฉลาดขึ้นแล้วนะ" (`outro`) **ไม่บังคับ** — เจ้าของช่อง 2026-11-23: "ไม่ต้องดันแว่นตลอดตอนจบก็ได้" (ตอนค้างแบบซีรีส์ จบที่ปมค้างได้เลย) → **การ์ด "ตอนหน้า: …"** (`next`) | `outro`, `next` |

- **ปมเปิดต้องเฉลยได้ด้วยข้อเท็จจริง** และทุกบรรทัดเป็นเหตุการณ์/ปฏิกิริยาของน้องสงสัย ต่อเนื่องเป็นเส้นเดียว (บทเรียน EP003 ที่ยกเลิก: เปิดด้วยปมที่เฉลยไม่ได้ + บรรยายข้อมูลแห้ง = "งง เปื่อย")
- เรื่องจริงต้องมี **ปมว้าว 2–3 จุด** (คลิปทดสอบ 31 วิมีน้อยเกิน) — ไม่ยืดด้วยการพูดช้า
- **โทนซาวด์คลอ:** `"mood": "dark"` (หลอน/ลี้ลับ) หรือ `"warm"` (อบอุ่น/ตลก/ชีวิต) ใน story.json; มีหัวใจเต้นอัตโนมัติเมื่อ `struggle`
- **ฉากที่มีใน `tools/story/scenes.js`:** `bedroom_night`, `bedroom_day`, `dark`, `cream`, `street_night` — เรื่องที่ต้องการฉาก/พร็อพใหม่ ให้ฝ่ายภาพเพิ่มเข้า `scenes.js` (ใช้ซ้ำได้ ไม่ทำเฉพาะตอน)
- การ์ดตอนหน้าตัดบรรทัดตามช่องว่าง — เขียนข้อความให้ไม่มีช่องว่างกลางวลี
- ข้อจำกัดตอนนี้: ตัวละครยังไม่มีปากขยับตอนพูด

## ตัวดึงคนดูกลับ (re-hook) — บังคับทุกตอน (เจ้าของช่องสั่ง 2026-11-22)
ช่วง **8–13 วินาที** คนดูมักปัดทิ้งเมื่อเรื่องเริ่มอธิบาย ทุกตอนต้องมีตัวดึงกลับในช่วงนี้ **อย่างน้อย 1 อย่าง** และซ้ำอีกครั้งราว 25–35 วินาที:
- **ปมค้าง (open loop)** ⭐ เจ้าของช่องชอบ — ประโยคที่บอกว่ามีบางอย่างรออยู่โดยไม่เฉลยทันที เช่น "แต่เดี๋ยวก่อน… มันไม่ใช่ผี!", "แต่ที่แปลกกว่านั้นคือ…"
- **ตุ้งแช่ / pattern interrupt** — `"jumpscare": "<ตัวละคร>"` ใน story.json (พุ่งเต็มจอ + แฟลช + จอสั่น + เสียง sting) ใช้กับเรื่องหลอน; เรื่องอื่นใช้การเปลี่ยนฉากกะทันหัน/ซูมแรงแทน
- **ภาพเปลี่ยนจังหวะ** — ห้ามฉากเดิมค้างเกิน ~4 วิ ช่วง 8–13 วิ

## กฎของบท
- 1 ประโยค = ไม่เกิน 3 วินาทีเมื่อพูด (หลังเร่ง tempo 1.2 ≈ ≤ 11 พยางค์ภาษาไทย — วัดจริง 3.7 พยางค์/วิ)
- บทเขียนเป็น `story.json` (ฉาก ตัวละคร ท่า effect) + `script.tts.txt` + `script.md` (ตารางย่อพร้อมรหัสแหล่ง F?) — ดูสคีมาใน `tools/story/build.py`
- ทุกประโยคต้องมี: ฉาก/ท่าตัวละคร และ (ถ้าเป็นข้อเท็จจริง) รหัสแหล่งอ้างอิงจาก fact sheet
- เสนอฮุก 3 แบบเสมอ

## เสียง
- เสียงพากย์: ElevenLabs (แพ็กเกจที่อนุญาตเชิงพาณิชย์เท่านั้น), ใช้เสียงจากคลังหรือเสียงเจ้าของช่อง — **ห้ามโคลนเสียงคนอื่น**
- ช่องว่างระหว่างประโยค ~0.2 วินาที (ขอบล่างของช่วง 0.2–0.4 ที่เจ้าของช่องกำหนด — เจ้าของช่องขอเร็วขึ้นอีก 2026-11-22)
- **อารมณ์เสียง (แท็ก eleven_v3):** ทุกบรรทัดใน `script.tts.txt` ขึ้นต้นด้วยแท็กอารมณ์ภาษาอังกฤษ 1 แท็ก
  - โทนหลักของช่อง = พลังสูง สดใส กวนๆ เทียบมาตรฐาน: `[excited] แต่มันหลอกสมองเธอ!` (เจ้าของช่องเลือกเป็นต้นแบบ) — เรื่องหลอนก็ยังใช้พลังสูง (`[surprised]` `[excited]`) ความหลอนมาจากภาพและซาวด์คลอ `dark` ไม่ใช่เสียงกระซิบ
  - แท็กที่ใช้ได้: `[excited]` `[mischievously]` `[playfully]` `[surprised]` `[curious]` `[smug]` `[laughs]` `[amazed]`
  - **ห้ามใช้** แท็กที่ดึงพลังเสียงลง: `[whispers]` `[sad]` `[sighs]` `[calm]` `[tired]` `[serious]` — ประโยคเชิงลุ้น ("แต่ที่แปลกคือ…") ให้ใช้ `[excited]` เท่านั้น — `[curious]` กับประโยคลากเสียง "…" ออกมาเบาเกิน (EP002 วัดได้ −19 LUFS เทียบบรรทัดอื่น −13 ถึง −16)
  - ไล่ระดับพลังให้มีขึ้นลง แต่ไม่ต่ำกว่าระดับ "พูดคุยสดใส"
- เสียงประกอบ: สร้างจากโค้ดใน `tools/sfx/` เท่านั้น — **ห้ามเพลง/เสียงที่มีลิขสิทธิ์เด็ดขาด**
- เสียงประกอบเบากว่าเสียงพากย์ชัดเจน (ประมาณ −18 ถึง −24 dB เทียบเสียงพากย์)
