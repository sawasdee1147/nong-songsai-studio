Cartoon Short (ฟรี) จาก Editarae, https://editarae.com

ติดตั้ง (ครั้งเดียว)
1. แตกไฟล์ zip นี้ ได้โฟลเดอร์ cartoon-short
2. ย้ายโฟลเดอร์ไปไว้ที่  ~/.claude/skills/cartoon-short
   (Mac: เปิด Finder > Go > Go to Folder > พิมพ์ ~/.claude/skills  ถ้าไม่มีโฟลเดอร์ skills ให้สร้างเอง)
3. เปิด Claude Code ในโฟลเดอร์ที่อยากเก็บงาน แล้วพิมพ์:
   ทำการ์ตูนเล่าเรื่อง เรื่อง <หัวข้อของคุณ>

Claude จะเขียนบท ให้คุณดูบทครั้งเดียว แล้วทำเสียง วาดฉาก ใส่ซับ ใส่เสียงประกอบ และเรนเดอร์ออกมาเป็น MP4 ให้เอง

เสียงพากย์ (แนะนำ): สมัคร ElevenLabs (elevenlabs.io แพ็กฟรีพอเริ่ม ราว 15-20 คลิป/เดือน) เสียงเหมือนคนจริง
สร้าง API key ที่ Developers > API Keys แล้วพิมพ์ใน Terminal เอง (อย่าวางคีย์ในแชท):
  echo 'คีย์ของคุณ' > ~/.elevenlabs_key
ถ้าไม่มีคีย์ สกิลจะใช้เสียงฟรีของ Google แทน (ฟังออกว่าเป็นเสียงเครื่อง)

ต้องมี: Claude Code, Python 3, Node 18+, ffmpeg  (Claude จะเช็คให้ตอนเริ่ม)
ทำเรื่องแนวไหนก็ได้ ผี ตลก ประวัติศาสตร์ ชีวิต ความรัก ภาพการ์ตูนสไตล์เดียวกันทุกเรื่อง
