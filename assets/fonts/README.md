# ฟอนต์
- Noto Sans Thai (น้ำหนัก 400/700/900, ชุดอักษรไทย) — จาก npm `@fontsource/noto-sans-thai@5.3.0`
- ใบอนุญาต: SIL Open Font License 1.1 (`OFL-LICENSE.txt`) — ใช้เชิงพาณิชย์ได้
- ใช้ในวิดีโอด้วย `@font-face` ชี้ไฟล์ในโปรเจกต์ ห้ามโหลดจาก CDN
- ตัวเลข/ละติน (เช่น "TRPV1", "40°C") ใช้ fallback `sans-serif` ของระบบ หรือเพิ่มไฟล์ latin ของ fontsource ถ้าต้องการให้ตรงสไตล์
