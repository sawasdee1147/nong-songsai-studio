# เสียงประกอบ (สร้างจากโค้ด)

ทุกเสียงสร้างด้วยคณิตศาสตร์ใน `make_sfx.py` (sine, noise, filter) — ไม่มีไฟล์เสียงจากภายนอก จึงไม่มีปัญหาลิขสิทธิ์
ต้องการเสียงใหม่: เพิ่มฟังก์ชันใน `make_sfx.py` แล้วลงทะเบียนใน `SFX` — **ห้ามดาวน์โหลดเสียงจากเว็บ**

```bash
python3 tools/sfx/make_sfx.py sfx/
```

| ชื่อ | ใช้ตอน |
|---|---|
| `pop` | ของโผล่/เด้งขึ้นจอ |
| `boing` | ตัวละครเด้ง ท่าซนๆ |
| `glint` | เลนส์แว่นแวบ (ท่าดันแว่น/แว่นแวบ) |
| `ding` | ปิ๊ง! เข้าใจแล้ว / เฉลย |
| `whoosh` | เปลี่ยนฉาก / ของพุ่งเข้า |
| `swoosh_down` | ของตก / ซูมออก |
| `bubble` | ฟองน้ำ 1 ฟอง |
| `bubbles` | ฟองน้ำหลายฟอง (ใต้น้ำ) |
| `splash` | จุ่มน้ำ / น้ำกระเซ็น |
| `tick` | ข้อความ/ไอคอนขึ้นทีละอัน |
| `thud` | ตกใจ / ข้อเท็จจริงหนักๆ |
| `riser` | สร้างความลุ้นก่อนเฉลย |
| `blip_talk` | ตัวละคร 'อืม?' แบบการ์ตูน |
| `wrong` | ผิด! / ความเชื่อผิด |
