# บท: ทำไมกินพริกแล้วรู้สึกร้อน?

## ฮุก (เลือก 1)
- **A** (แนะนำ) "พริกไม่ใช่ของร้อน!" / "แต่มันหลอกสมองเธอ!" (5 + 6 พยางค์ แยก 2 ประโยค) — ภาพ: เฟรมแรกพริกแดงใส่ "หน้ากากเปลวไฟ" ยืนเท่ๆ กลางจอ หน้ากากหลุดร่วงลงเองด้วยอนิเมชั่น (ตัวละครไม่ได้ดึง) ข้างในเป็นพริกธรรมดาหน้ากวนๆ น้องสงสัยชี้ (`arm:"point"`) ป้ายเด้ง "พริก ≠ ไฟ" (F1, F7) — เหตุผล: ขัดความเชื่อที่ทุกคนมีตั้งแต่คำแรก ไม่ต้องเกริ่น ประโยคแรกจบในราว 1.5 วิ ภาพหน้ากากหลุดเล่าเรื่องได้แม้ปิดเสียง และพาเข้าคำตอบหลักของคลิป (พริกหลอกตัวรับร้อน) ได้ตรงๆ เรื่องโนเบลเก็บไว้เป็นจุดว้าวท้ายคลิปให้คนดูจนจบ
- **B** "สารในพริก เป็นกุญแจสู่รางวัลโนเบล!" (11 พยางค์) — ภาพ: พริกวางนิ่งๆ โมเลกุลแคปไซซินลอยออกมากลายเป็นกุญแจ ไขกล่อง แล้วเหรียญวาดเองแบบเรียบ (วงกลมเหลือง `#FFD84D` + ริบบิ้น + ตัวหนังสือ "Nobel 2021 · David Julius") เด้งออกมา ข้อความเล็กแยกใต้เหรียญ "(ร่วมกับ Ardem Patapoutian — ค้นพบตัวรับแรงกด)" ห้ามหน้าคน ห้ามเลียนแบบเหรียญจริง/โลโก้/ตรา/ฟอนต์ของมูลนิธิโนเบล น้องสงสัยท่าตกใจ (F10, F11) — ช่องว่างความอยากรู้: พริกเกี่ยวกับโนเบลยังไง
- **C** "แสบเหมือนไฟไหม้ แต่ไม่ได้ไหม้จริง!" (9 พยางค์) — ภาพแปลก: น้องสงสัยท่าตกใจกัดพริกคำเดียว ผมชี้ซิกแซก พ่นไฟการ์ตูนออกปาก มีไอแดงทับแก้ม (`extra` สีชมพูแก้ม `#FF9AA2` / ส้มเข้ม `#E0704F`) + หยดเหงื่อ — **ห้ามเปลี่ยนสีผิว** แล้วภาพหยุดนิ่ง มีตราประทับ "ไม่ได้ไหม้จริง!" ทับ (F7) — ใช้ภาพตลกหยุดนิ้วก่อน แล้วค่อยหักมุมด้วยคำพูด

### หมายเหตุสำหรับทีม
- ประโยคที่มีภาพประกอบเนื้อหา: 16/18 (ยกเว้นบรรทัดปิดประจำ)
- จุด "เหตุผลใหม่ให้ดูต่อ": #1a ขัดความเชื่อ → #3 เฉลยสาร → #7a "แต่ที่แปลกคือ…" (~17 วิ) → #9a–10 สมอง/ร่างกายโดนหลอก (~22 วิ) → #11 เผ็ดไม่ใช่รสชาติ (~28 วิ) → #13 โนเบล (~32 วิ)
- ข้อระวังที่เคารพ: ไม่พูด 43 องศา (ใช้ "ประมาณ 40 องศาขึ้นไป") · ไม่พูดว่าปากไม่ร้อนขึ้นเลย/0 องศา · ไม่พูดว่า TRPV1 เป็นตัวรับร้อนตัวเดียว · ไม่พูดว่าลิ้นไหม้จริง (#9b พูด "ไม่ได้ไหม้จริง" ตามที่ fact sheet อนุญาต) · ไม่พูด "ไม่เกี่ยวกับรสชาติเลย" · ไม่ใช้เรื่องนก นม สโกวิลล์ น้ำมูก/น้ำตา สรรพคุณสุขภาพ · โนเบลระบุว่าได้ร่วมกัน
- F21 (เหงื่อ) ความมั่นใจกลาง ใช้เป็นจุดเสริม ไม่ใช่จุดว้าวหลัก
- ซับ #6 แสดง "40" เป็นตัวเลข ส่วนไฟล์ TTS เขียนเป็นคำอ่าน
- วิธีนับพยางค์: นับตามเสียงอ่าน เช่น ปกติ = ปะ-กะ-ติ (3), สมอง = สะ-หมอง (2), รสชาติ = รด-ชาด (2), ฉลาด = ฉะ-หลาด (2), สัญญาณ = สัน-ยาน (2), กุญแจ = กุน-แจ (2)

## สรุปสิ่งที่แก้ (รอบ 2 — ตาม factcheck.md และ qa-script.md)
1. **#5** "ปกติมันเปิด…" → "ปกติประตูนี้เปิดเมื่อร้อนจนเจ็บ" แก้ทั้งซับและ TTS (11 พยางค์ นับ ปกติ = 3)
2. **#11 ภาพ** ป้ายรสครบ 5 รส (หวาน เค็ม เปรี้ยว ขม อูมามิ) แล้วช่อง "เผ็ด" ต่อท้ายโดนกากบาท
3. **#10 ท่า** เลิกใช้ท่าเขินๆ → ใช้ preset ตกใจ + `extra` หยดเหงื่อ/ไอแดงทับแก้ม สีจากชุดสีช่อง เขียนกำกับ "ห้ามเปลี่ยนสีผิว" · **ฮุก C** ตัด "หน้าแดงเถือก" ใช้วิธีเดียวกัน
4. **ฮุก B** → "สารในพริก เป็นกุญแจสู่รางวัลโนเบล!" และภาพระบุผู้ร่วมรับรางวัล
5. **#13 + ฮุก B ภาพ** เหรียญวาดเองแบบเรียบ ห้ามหน้าคน/โลโก้/ตรา/ฟอนต์มูลนิธิ บนเหรียญเขียนแค่ "Nobel 2021 · David Julius" ชื่อ Patapoutian แยกเป็นข้อความเล็กด้านล่าง "(ร่วมกับ Ardem Patapoutian — ค้นพบตัวรับแรงกด)"
6. **#15** ซับไม่ใส่อีโมจิ 🤓 (ระบุในคอลัมน์ภาพ)
7. **นับพยางค์ใหม่ทุกประโยค:** #11 8 → 7, #14 7 → 5, #5 = 11 · ประโยคอื่นตรวจซ้ำแล้วค่าเดิม · รวม 136 → 135 (หลังแยกประโยค)
8. **ท่าแขน:** #1a หน้ากากหลุดเองด้วยอนิเมชั่น ตัวละครใช้ `arm:"point"` ชี้ · #8 ใช้ preset ตกใจ (`arm:"up"`) ตรงๆ
9. **SFX #9** ไม่ใช้ไซเรน/blip_talk → #9a `thud` (ไฟเตือนกะพริบเป็นภาพอย่างเดียว) #9b `boing` (พริกเด้งยักไหล่) · #10 `bubble` ระบุว่าตั้งใจเป็นเสียงหยดเหงื่อ
10. **แยกประโยคที่มีจังหวะเว้น** โดยคงถ้อยคำเดิมที่ผ่าน factcheck ทุกคำ: #1 → 1a/1b, #7 → 7a/7b, #9 → 9a/9b · จาก 15 เป็น 18 ประโยค ทุกประโยค ≤ 11 พยางค์
