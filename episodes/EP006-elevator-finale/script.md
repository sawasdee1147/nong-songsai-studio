# บท: ใครเคาะจากใต้พื้นลิฟต์? (Ep.3 ตอนจบซีรีส์) · mood: dark · ประมาณ 64 วิ (24 บรรทัด)

## ฉากใหม่ที่ต้องสร้าง (ให้น้อยที่สุด — นิคส่ง animator)
1. **`elevator_pit`** (บรรทัด 11–12) มุมใต้พื้นลิฟต์ในหลุมใต้ลิฟต์: เพดานเป็นท้องลิฟต์เหล็กหนาเห็นเส้นขอบ, สปริงกันกระแทก 1–2 ตัวข้างฉาก, แสงไฟคาดหัวช่างส่องเป็นวงสว่างในที่มืด · **ห้ามดูเหมือนห้องกว้าง/ปลอดภัย ไม่ใส่ขนาด** · ถ้ายังไม่ทำ ใช้ `dark` แทน
2. **`lobby_police`** (บรรทัด 20) ล็อบบี้ตึกกลางคืน/หน้าประตูลิฟต์เปิด มีแสงสีฟ้า-แดงกะพริบสาดจากด้านนอก (ไม่ต้องมีตัวตำรวจ) · ใช้แสงกะพริบช้า ปลอดภัยต่อผู้ไวแสง · ถ้ายังไม่ทำ ใช้ `street_night` + แสงฟ้า-แดงทับ
3. **พร็อพตัวละคร** (ผ่าน cast key `hat` / `lamp` — ถ้า kid.js ยังไม่รองรับ ขอเพิ่ม option หรือใช้ `extra`):
   - `YH` = Y เดิม + **หมวกยามทรงแก๊ป** (ต้องเป็นหมวกยามดูออก; ถ้าเสียงเรียก "หมวกยามปลอม" ภาพต้องดูแปลกพอ เช่น ป้ายหมวกเอียง)
   - `W` = **หมวกนิรภัยเหลือง + ไฟคาดหัวมีวงแสง**, เสื้อเขียว — ห้ามแว่นกลม/ผมชี้ (ตั้งค่าไว้แล้ว)
4. หมายเหตุเสียง: ลุง Z ใช้ `"speaker":"Y"` เหมือน EP005 (voices["Y"] ใน voice.json = เสียงลุง) · W ไม่พูด

- **A** (แนะนำ, **H2 ช่องว่างความอยากรู้** + นาฬิกา) "ตีสองยี่สิบห้า เสียงเคาะดังใต้เท้าคุณ!" — ภาพ: คุณเอามือปิดหน้า จอสั่น เสียงเคาะ — เหตุผล: ปมค้างจากตอนที่แล้ว ต่อได้เลยแม้ไม่เคยดู; ประเภทใหม่ที่ยังไม่เคยใช้ (H2 = 0 ตอน) สอดคล้องกติกาหมุนเวียน

- **C** (H1 ขัดความเชื่อ) "ลิฟต์ค้าง ห้ามกดปุ่มชั้นเด็ดขาด!" — ภาพ: คุณกดปุ่มรัว แล้วป้ายแดงตัดเข้ามา (สปอยล์กฎ จึงไม่แนะนำเท่า A)
