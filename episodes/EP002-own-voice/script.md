# บท: ทำไมเสียงตัวเองในคลิปฟังแปลก?

## ฮุก (เลือก 1)
- **A** (แนะนำ) **[H4 ท้าทายคนดู]** "ลองอุดหูแล้วพูดดิ!" / "เสียงเธอดังขึ้นแถมทุ้มด้วย!" (6 + 7 พยางค์ แยก 2 ประโยค) — ภาพ: เฟรมแรกน้องสงสัยเต็มจอใส่ **ที่อุดหูการ์ตูน** สีเหลือง `#FFD84D` (วาดเป็น `extra` ที่ตำแหน่งหูทั้ง 2 ข้าง — ไม่ใช้มือ/นิ้ว เพราะไม่มีท่าแขนนี้) ชี้มาที่คนดู ป้ายเด้ง "ลองดิ!" → พอประโยค 1b คลื่นสีส้มยาวห่างๆ "บูม" ขยายในหัว มีเส้นขอบ "ถัง" การ์ตูนโปร่งรอบหัว (มุก "พูดในถัง") หน้ายังเห็นชัด (F9, F10) — เหตุผล: (1) เป็นประเภทที่ยังไม่เคยใช้ ได้ข้อมูลใหม่ตามกฎหมุนเวียน และไม่ต่อ H1 จาก EP001 (2) คนดูทำตามได้ทันทีในวินาทีแรก = เหตุผลให้ค้างดู/คอมเมนต์ "ทำตามแล้วจริง!" (3) มีจุดเฉลยกลับมาตอนท้าย (#13a–13c) ทำให้คนดูจนจบ
- **B** **[H1 ขัดความเชื่อ]** "เสียงในหัวเธอ คนอื่นไม่เคยได้ยิน!" (10 พยางค์) — ภาพ: น้องสงสัยท่าตกใจ ข้างๆ เป็นไอคอนเพื่อนแบบเรียบ ในหัวน้องสงสัยมีคลื่นส้ม+ฟ้า ส่วนเพื่อนได้รับแค่คลื่นฟ้า ป้าย "เธอ: ส้ม+ฟ้า / เพื่อน: ฟ้า" (F2, F3, F4) — ประเภทเดียวที่มีข้อมูลแล้ว (ใช้ได้อีก 1 ตอนโดยไม่ผิดกฎ 2 ตอนติด) ถ้าเลือก B ให้ตัด #1a–1b แล้วเริ่มที่ #2
- **C** **[H3 ภาพแปลก/ตลกหยุดนิ้ว]** "นี่เสียงฉันจริงดิ!?" (5 พยางค์) — ภาพ: มือถือการ์ตูนเล่นคลิปเสียง มีคลื่นฟ้าพุ่งออกจากลำโพง น้องสงสัยท่าตกใจ (`gl:"askew"`, `ah:"zig"`) ผมชี้ซิกแซกเด้งสูงพร้อม `boing` เครื่องหมาย "?" 3 อันหมุนรอบหัว ป้ายบนจอมือถือ "เสียงฉัน??" (F5, F20 — พูดแค่ "แปลก") — ภาพตลกหยุดนิ้วแม้ปิดเสียง ถ้าเลือก C ให้แทน #1a–1b ด้วยประโยคนี้แล้วต่อ #2

### หมายเหตุสำหรับทีม
- ทุกประโยค ≤ 10 พยางค์ (ยาวสุด #7 = 10 พยางค์ ≈ 2.7 วิแม้พูดช้าลง 15%) — ถ้า #7 ยังเกิน 3.0 วิ ให้แยกเป็น 7a "ส่วนคนอื่นได้ยินเสียงเธอ" / 7b "ทางอากาศ"
- ประโยคที่มีภาพประกอบเนื้อหา: 18/20 (ยกเว้นบรรทัดปิดประจำ)
- จุด "เหตุผลใหม่ให้ดูต่อ": #1a ท้าให้ลอง → #2 ตั้งคำถามหลัก (~4 วิ) → #4 เฉลย 2 ทาง (~9 วิ) → #8a ล้มความเชื่อไมค์ห่วย (~18 วิ) → #11 "แต่ที่ฮากว่าคือ…" (~26 วิ) → #13a เฉลยฮุกที่ท้าไว้ (~32 วิ)
- คำว่า "มัน" ไม่มีในบทเลย · "ทางนี้" (#6) กำกับด้วยภาพสายส้มกะพริบ
- ข้อความเล็กทุกป้ายย่อเหลือ ≤ 4 คำ และค้าง ≥ 2 วิ (ระบุในคอลัมน์ภาพ)
- ข้อระวังที่เคารพ (หมวดห้ามพูด): ไม่มีตัวเลขความถี่/Hz และไม่พูดว่ากะโหลก "กรองเสียงแหลม" (#5 พูดแค่ "ทุ้มขึ้น") · ไม่พูดว่าเสียงในคลิป = เสียงที่คนอื่นได้ยินเป๊ะ และไม่อ้างไมค์/แอป/ฟิลเตอร์ใดทำให้เหมือนในหัว (#8a–8b พูดแค่ว่าไมค์อัดได้ทางอากาศ) · ใช้ "หนึ่งในเหตุผลหลัก" (#10) ไม่ใช่ "เหตุผลเดียว" · ไม่ใช้ 38% / Hughes & Harrison / บุคลิกในเสียง · ไม่พูด "ทุกคนเกลียดเสียงตัวเอง" (#2, #9 ใช้ "แปลก" / "ไม่คุ้นหู") · ไม่ใช้เบโธเฟน / Cardano · ไม่ใช้ F16 (79%/17%) และ F18 bone conduction headphone · **ไม่ใช้เรื่องลูกตา (F21)** — ตัดออกเพื่อคุมความยาวและไม่ต้องใส่คำเตือนทางการแพทย์
- #12a–12b (F14) พูดแบบทั่วไปตามแหล่ง ("แม่นน้อยกว่า") ภาพมีป้าย "งานวิจัยส่วนใหญ่พบ" ตามถ้อยคำ fact sheet
- #13b (F9) "ได้ยินแต่ทางกระดูก" ตามถ้อยคำ fact sheet; #1b "ดังขึ้น ทุ้ม" ตาม F10 (ใช้ "อุดหู" แบบทั่วไป/ที่อุดหู ซึ่ง F9 ความมั่นใจสูง ไม่ได้อ้าง F11 นิ้วอุดหู)
- ท่าตัวละคร: ใช้เฉพาะ preset/option ใน `character/README.md` · ไม่มีท่าเอานิ้วอุดหู → ที่อุดหูวาดเป็น `extra` · ไม่มีท่าเขิน/มือบังหน้า · ไม่เปลี่ยนสีผิว · เส้นถัง (#1b) เป็นเส้นขอบโปร่งไม่บังหน้า
- SFX ทั้งหมดอยู่ในรายการ `tools/sfx/README.md`
- วิธีนับพยางค์: นับตามเสียงอ่าน เช่น อากาศ = อา-กาด (2), กระดูก = กระ-ดูก (2), เหตุผล = เหด-ผน (2), ไมค์ = 1
