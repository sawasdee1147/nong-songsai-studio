# บท: ทำไมเสียงตัวเองในคลิปฟังแปลก?

## ฮุก (นิคเลือก A — H4 ท้าทายคนดู)
- **A** **[H4 ท้าทายคนดู]** "ลองอุดหูแล้วพูดดิ!" / "เสียงเธอดังขึ้นแถมทุ้มด้วย!" (6 + 7 พยางค์ แยก 2 ประโยค) — ภาพ: น้องสงสัยใส่ที่อุดหูการ์ตูน (สเปกด้านล่าง) ชี้ไปที่ป้าย "ลองดิ!" ทางขวาจอ → 1b คลื่นวงแหวนส้มก้องอยู่ข้างหัว/รอบหูด้านนอก + เส้นขอบ "ถัง" นอกวงหัว (มุก "พูดในถัง" — S4 "talking in a barrel") (F9, F10) — เหตุผล: ประเภทที่ยังไม่เคยใช้ ไม่ต่อ H1 จาก EP001, คนดูทำตามได้ทันที, มีจุดเฉลยกลับมาที่ #13a–13b
- ถ้อยคำฮุก **ไม่ระบุวิธีอุดหู** ("ลองอุดหู") และภาพแสดงเฉพาะที่อุดหู (F9) — กลไก occlusion effect (F10, S4) ใช้ได้กับคนหูปกติ

- ชิ้นเล็ก **เล็กกว่าใบหู** สีเหลือง `#FFD84D` เส้นขอบ `#2B2B2B` ทรงดอกเห็ด/กระบอกสั้น โผล่ออกจาก **รูหู** ด้านนอกของวงรีหู (หูใน `kid.js` = วงรี cx 60/240, cy 160, rx 10, ry 16) ใบหูสีผิวยังเห็นรอบๆ ชัด → **หูต้องไม่ดูเปลี่ยนสี**
- **ห้ามทับเลนส์แว่น** (ทับได้แค่ปลายขาแว่น x 64/236) — `extra` วาดชั้นบนสุดเหนือแว่น ระวังเหมือนบทเรียน EP001
- **ช่วงที่ใส่:** #1a–1b และ #13a–13b · **ถอดออก:** ต้นประโยค #2 ที่อุดหูเด้งหลุดออกพร้อมถังหายไป (`pop`) และหลุดอีกครั้งตอนจบ #13b ก่อนเข้าท่าปิด #14 (ฉากฟังคลิป #10 และท่าดันแว่นต้องไม่มีที่อุดหู)

### หมายเหตุสำหรับทีม
- ทุกประโยค ≤ 8 พยางค์ · ประโยคที่มีเว้นกลาง: #3 แยก 3a/3b แล้ว · #10 "นี่แหละ หนึ่งในเหตุผลหลัก!" (7) และ #12b "ฟังเสียงอัด เราจำเสียงตัวเอง" (8) ความเสี่ยงต่ำ ถ้า #12b เกิน 3.0 วิ ให้แยก "ฟังเสียงอัด" / "เราจำเสียงตัวเอง"
- ประโยคที่มีภาพประกอบเนื้อหา: 17/19 (ยกเว้นบรรทัดปิดประจำ)
- จุด "เหตุผลใหม่ให้ดูต่อ": #1a ท้าให้ลอง → #2 คำถามหลัก (~4 วิ) → #4 เฉลย 2 ทาง (~9 วิ) → #8a ล้มความเชื่อไมค์ห่วย (~17 วิ) → #11 "แต่ที่แปลกกว่าคือ…" (~23 วิ) → #13a ย้อนเฉลยฮุก (~32 วิ)
- คำว่า "มัน" ไม่มีในบท · ป้ายบนจอใช้คำ "อากาศ" / "กระดูก" แทนรหัสสี ไม่เกิน 2 แถว และค้าง ≥ 2 วิ
- ตัวละครยืนซ้าย-กลางจอตลอด ภาพประกอบอยู่ทางขวา (ทิศ `arm:"point"`)
- ข้อระวังที่เคารพ (หมวดห้ามพูด): ไม่มี Hz/"กรองเสียงแหลม" · ไม่พูดว่าคลิป = ที่คนอื่นได้ยินเป๊ะ · ไม่อ้างไมค์/แอป/ฟิลเตอร์ · "หนึ่งในเหตุผลหลัก" · F14 พูดพร้อม "งานวิจัยส่วนใหญ่" ในเสียงและซับ · ไม่ใช้ 38%, Hughes & Harrison, "ทุกคนเกลียดเสียงตัวเอง", เบโธเฟน, Cardano, F16, F18, F21 (ลูกตา)
- **ถึงนักการตลาด:** แคปชัน/ปก/คอมเมนต์ปักหมุด **ห้ามชวนเอาของอื่นใส่หู** (สำลีก้าน ฯลฯ) ให้ใช้คำว่า "ลองอุดหู" แบบไม่ระบุวิธี หรือ "ใช้ที่อุดหู" เท่านั้น
- ท่าตัวละคร: ใช้เฉพาะ preset/option ใน `character/README.md` · ไม่มีท่าเขิน/มือบังหน้า · ไม่เปลี่ยนสีผิว · ไม่วาดแขนใหม่
- SFX ทั้งหมดอยู่ในรายการ `tools/sfx/README.md`
- วิธีนับพยางค์: นับตามเสียงอ่าน เช่น อากาศ = อา-กาด (2), กระดูก = กระ-ดูก (2), เหตุผล = เหด-ผน (2), งานวิจัย = งาน-วิ-จัย (3), ไมค์ = 1
