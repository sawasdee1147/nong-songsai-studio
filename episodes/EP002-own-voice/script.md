# บท: ทำไมเสียงตัวเองในคลิปฟังแปลก?

## ฮุก (นิคเลือก A — H4 ท้าทายคนดู)
- **A** **[H4 ท้าทายคนดู]** "ลองอุดหูแล้วพูดดิ!" / "เสียงคุณดังขึ้นแถมทุ้มด้วย!" (6 + 7 พยางค์ แยก 2 ประโยค) — ภาพ: น้องสงสัยใส่ที่อุดหูการ์ตูน (สเปกด้านล่าง) ชี้ไปที่ป้าย "ลองดิ!" ทางขวาจอ → 1b คลื่นวงแหวนส้มก้องอยู่ข้างหัว/รอบหูด้านนอก + เส้นขอบ "ถัง" นอกวงหัว (มุก "พูดในถัง" — S4 "talking in a barrel") (F9, F10) — เหตุผล: ประเภทที่ยังไม่เคยใช้ ไม่ต่อ H1 จาก EP001, คนดูทำตามได้ทันที, มีจุดเฉลยกลับมาที่ #13a–13b
- ถ้อยคำฮุก **ไม่ระบุวิธีอุดหู** ("ลองอุดหู") และภาพแสดงเฉพาะที่อุดหู (F9) — กลไก occlusion effect (F10, S4) ใช้ได้กับคนหูปกติ

- **ช่วงที่ใส่:** #1a–1b และ #13a–13b · **ถอดออก:** ต้นประโยค #2 ที่อุดหูเด้งหลุดออกพร้อมถังหายไป (`pop`) และหลุดอีกครั้งตอนจบ #13b ก่อนเข้าท่าปิด #14 (ฉากฟังคลิป #10 และท่าดันแว่นต้องไม่มีที่อุดหู)

### หมายเหตุสำหรับทีม
- ทุกประโยค ≤ 9 พยางค์ (ประโยคใหม่ 5b, 12d, 12e, 12g = 9 พยางค์ ≈ 2.6 วิก่อนเร่ง) · ประโยคที่มีเว้นกลาง: #3 แยก 3a/3b แล้ว · #10 "นี่แหละ หนึ่งในเหตุผลหลัก!" (7) และ #12b "ฟังเสียงอัด เราจำเสียงตัวเอง" (8) ความเสี่ยงต่ำ ถ้า #12b เกิน 3.0 วิ ให้แยก "ฟังเสียงอัด" / "เราจำเสียงตัวเอง"
- ประโยคที่มีภาพประกอบเนื้อหา: 24/26 (ยกเว้นบรรทัดปิดประจำ) ภาพประโยคใหม่ทั้งหมดอยู่ขวาจอ
- จุด "เหตุผลใหม่ให้ดูต่อ" (เวลาหลังเร่ง): #1a ท้าให้ลอง → #2 คำถามหลัก (~4 วิ) → #4 เฉลย 2 ทาง (~8 วิ) → #5a–5c หัวสั่น + นักวิทย์ยังงง (~12 วิ) → #8a ล้มความเชื่อไมค์ห่วย (~20 วิ) → #11 "แต่ที่แปลกกว่าคือ…" (~26 วิ) → #12d–12g การทดลอง "อา" หลงเสียงเพื่อน 17% (~33 วิ) → #13a ย้อนเฉลยฮุก (~43 วิ)
- คำว่า "มัน" ไม่มีในบท · ป้ายบนจอใช้คำ "อากาศ" / "กระดูก" แทนรหัสสี ไม่เกิน 2 แถว และค้าง ≥ 2 วิ
- ตัวละครยืนซ้าย-กลางจอตลอด ภาพประกอบอยู่ทางขวา (ทิศ `arm:"point"`)
